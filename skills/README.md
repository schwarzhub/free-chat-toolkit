# skills/

A **skill** is *instructions, not code* — a packaged description (and sometimes example files) that
teaches the model *how* to approach a task using capabilities it already has. The model reads it;
nothing new executes. (See [what a skill is](../README.md#skill).)

*None yet.* Propose one as an issue or a PR here — a `SKILL.md`-style write-up: what the skill is
for, when the model should reach for it, and the step-by-step procedure. Keep it within the repo's
[out-of-bounds](../README.md#out-of-bounds--for-this-stage-of-development) rules.
